# 爬蟲原文驗證（2026-11-03）

本次驗證確認原程式仍有資訊漏抓、關鍵字欄位空白及收錄誤判，不能以「工作流程成功」代表新聞判讀正確。本次修正保留資料 PR 複核制度；候選仍不直接納入統計。

## 驗證範圍與方式

- 連線查詢 2026-10-31–11-02 的 38 筆搜尋結果，以及 2026-05-26–27 的 51 筆結果。
- 另取 9 篇已知新聞對照。共保留 92 份文章頁面回應，包含一篇重疊；不是 92 起事故。
- 以相同 HTML 重播實際 CLI，排除新聞更新及網路波動對前後比較的干擾。確認 17 篇保留候選的標題、發布日期、摘要排除圖片說明，以及複核旗標；另對 15 組重點判斷逐項比對原文。
- 將重現問題縮成回歸案例，先確認舊版失敗，再驗證修正版本。這些測試是特定案例的保護，不是全站準確率估計。
- 所有試抓寫入暫存副本，沒有執行歷史清理腳本或覆寫正式資料。

修正後 45 項自動測試、資料格式檢查與 Pages 建置通過；再次連線試抓近期區間得到 2 筆符合本次複核的候選，85 筆既有紀錄逐筆比對均未改動。

## 1. 新聞資訊是否正確

原文標題與發布日期在本次保留樣本中一致。原摘要會混入圖片說明，已移除 `.photo`。原城市判斷按照城市清單順位取值，遇到高雄追到台南的報導會選錯城市，已改為優先採明確行駛／事故地點，再依文中出現順序判定；只有「新竹」「嘉義」而無縣市依據時留空。

`publishedAt` 代表新聞發布日。例如高雄逆向騎人行道案發布於 11 月 1 日，內文所述事發時間更早。程式沒有提供獨立的事故發生日，不能把發布日期當作事故日期。

歷史回補曾因一篇評論頁沒有新聞內文而整批停止。現在先依明確的政策／評論／司法後續標題排除，並在執行報告註明沒有擷取事故內文；應收錄文章若抓取失敗，仍會整批失敗，不發布部分結果。

## 2. 關鍵字是否擷取

舊版新候選的 `extractedDetails` 全部為空物件，因此網站沒有可讀取的毒品、檢測與行為標籤。已補上：

- 毒品名稱與別稱正規化，例如愷他命 → K 他命、依託咪酯 → 依托咪酯、安毒／甲基安非它命 → 安非他命、喪屍菸彈 → 喪屍煙彈。
- 唾液、尿液與血液檢測文字；拒絕、未實施或僅預定的檢測不作為已執行方式。
- 明確駕駛動詞後的載具，以及逆向、闖紅燈、拒檢逃逸、碰撞等行為。
- 過往案例、宣導與否定文字的過濾；偵測到多案時暫停人物與數量合併。

關鍵字仍是報導提及的標籤。查獲、當事人自述與化驗確認的證據強度不同，目前不會自動產生司法認定或毒品級別。載具若只能靠品牌或人物關係推論，也可能維持空白。

## 仍有限制

1. 有明確數字或明確全案零傷亡的句型，才能自動填值。人物逐一敘述、傷者後續死亡、不同報導更新與矛盾文字仍需人工彙總；`null` 不能用來證明沒有死傷。
2. 自動搜尋依賴 LTN 的索引與關鍵字，不代表完整新聞覆蓋率；保守標題規則仍可能漏掉僅在內文描述危險的事件。
3. 多案辨識與縣市、駕駛角色判斷仍是規則式。未匹配的語句不保證正確，也不保證已偵測全部多案。
4. 既有 URL／標題會跳過，不會自動同步原文的新傷亡或檢測結果。同事故不同標題也可能成為不同候選，必須在 PR 去重。
5. 本次未逐筆重新認證既有 85 筆正式資料，也未把新候選改成可直接納入統計。

## 本機重跑

```bash
npm test
npm run data:validate
GITHUB_PAGES=true npm run build

news_check_dir=$(mktemp -d)
cp public/data/incidents.json "$news_check_dir/incidents.json"
npm run data:news -- --start 2026-10-31 --end 2026-11-02 \
  --output "$news_check_dir/incidents.json" \
  --report "$news_check_dir/report.json"
cat "$news_check_dir/report.json"
```

既有資料會去重，因此重跑新增數取決於副本已有的紀錄。連線搜尋結果及原文也會更新，不能以候選筆數不變作為唯一驗證。
