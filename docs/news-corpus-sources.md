# 新聞詞典與語料來源盤點

查證日期：2026-11-03。目的：支援 jieba 斷詞、人物與事件關聯重整，減少人工從頭整理用語及逐篇配對的時間。本文件是資料盤點與設計建議，未下載整套外部語料、未訓練模型，也未把新詞自動加入正式詞典。

## 可用的線上資源

| 資源 | 已有內容 | 對本專案的用途與限制 |
|---|---|---|
| [jieba 官方詞典](https://github.com/fxsjy/jieba) | `dict.txt.big` 提供較完整的繁體支援，也可載入自訂詞典 | 作為一般詞彙基底，再疊加毒品、檢測、交通用語。它是詞典，不是已標註人物與事件的新聞資料。倉庫採 [MIT 授權](https://github.com/fxsjy/jieba/blob/master/LICENSE)。 |
| [法務部反毒大本營](https://antidrug.moj.gov.tw/lp-25-1.html) | 毒品及相關濫用物質的名稱、別稱與說明 | 提供有來源的領域用語；不能把所有列出的濫用物質一律當作法定毒品，也不能把俗稱直接當作某成分的證明。頁面有 [資料開放宣告](https://antidrug.moj.gov.tw/cp-133-6411-1.html)，使用時記錄來源並依其範圍、例外與署名要求處理。 |
| [中研院現代漢語平衡語料庫 ASBC 4.0](https://asbc.iis.sinica.edu.tw/index_readme.htm) | 約一千一百萬詞，已有斷詞及詞類標記；文章年代為 1981–2007 | 可查一般中文用法及標記方式，無法直接涵蓋近年的毒品俗稱與事故關係。[授權協議](https://www.aclclp.org.tw/doc/asbc_agr_c.pdf) 限制商業衍生使用與轉交第三方，不能把它當作可任意放進公開 repository 的語料。 |

另有 [CKIP Transformers](https://github.com/ckiplab/ckip-transformers) 可在 CPU 執行斷詞、詞性與實體辨識，但這是本機預訓練工具，不是可直接下載的完整訓練語料。它也不直接解決跨篇同案、親屬指代或傷亡狀態；目前未採納為新依賴，仍維持使用者選擇的 jieba 與事件規則方向。

## 過去新聞可以如何使用

歷史新聞可提供真實的台灣毒品俗稱、警方用語、事故句型與同案後續報導，適合成為本專案的領域語料。但原文、斷詞標註、人物／事件標註是不同資料，載入文章不會讓 jieba 自動學會誰是駕駛或誰死亡。

建議分三層處理：

1. **原文層**：來源 URL、發布／擷取時間、正文版本及雜湊，供重現與核對。先依來源的使用條件處理，未確認再散布條件的全文不直接打包成公開語料。
2. **詞彙候選層**：統計文章中反覆出現的詞組、不同來源中的用法，以及它們與「查獲、施用、檢測」等上下文的關聯。合併重複候選，附少量原文例子；有權威來源的名稱與只有新聞推測的新詞分開。
3. **事件標註層**：紀錄人物別稱、角色、所屬事件、檢測對象、否定／疑似、時間、傷亡狀態及同案關係。程式可先產生候選以節省工時，但自動推測不直接升格為已核對的答案。

## 以減少人工介入為目標的建議

一般詞彙使用現成繁體詞典；領域名稱從有來源的官方資料建立；歷史新聞負責補足實際句型及新用語。由程式先整理詞彙候選、人物關係、同案配對和更新內容，複核只集中在未知用語、身份歧義、證據衝突及重要數值變更。詞典候選按詞組去重、事件候選按同案整理，避免每篇都要求重複確認。

對 jieba 而言，最先需要的是可追溯的自訂詞典與詞頻設定，不必先從零訓練斷詞模型。HMM 開關與候選新詞用法仍須在設計中明確決定；新聞詞頻不會自動重訓 jieba 內建 HMM，也不等於已學到事件關係。

上述接入及自動採用界線仍屬提案；實際狀態見 [設計訪談](news-tokenization-design.md)。
