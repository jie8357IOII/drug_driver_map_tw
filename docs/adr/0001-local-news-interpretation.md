# 新聞判讀採本機處理，候選資料經 PR 複核

2026-11-03 後續需求已改為同時收錄酒駕、允許免費 API 或規則判讀，並以每日直接更新網站為目標；本 ADR 的「不使用模型 API」與「每批人工合併 PR」不再是現行約束。[ADR-0002](0002-automatic-news-publication.md) 已確認新聞先發布、疑義欄位暫緩及數值衝突保留原值的界線；詳見 [每日新聞自動更新規劃](../daily-alcohol-drug-news-plan.md)。API 選型尚待技術比較，新流程尚未部署。

使用者明確選擇不呼叫模型 API，並在 2026-11-03 確認採用「jieba＋專用詞典＋事件規則」，且本次一併重整人物與事件關聯；本機與 GitHub Actions 必須能執行同一套流程。這項選擇使判讀依據能與程式、詞典一起保存，但也需要持續維護新聞句型與人物關聯規則，斷詞本身不能確認毒駕或傷亡事實。斷詞環境或詞典故障時停止更新並保留既有資料；正常產出維持待複核資料 PR，合併後才更新網站，新詞處理與跨篇關聯的具體範圍仍在訪談，此 ADR 不表示接入已完成。
