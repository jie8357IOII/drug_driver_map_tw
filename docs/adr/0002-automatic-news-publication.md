# 酒駕與毒駕新聞自動發布，事件與欄位分別核對

為減少每日人工介入，使用者於 2026-11-03 確認酒駕與毒駕共用每日自動更新流程：具體事件可進地圖，政策、判決與統計報導另放新聞區，日常資料不再以逐批人工合併 PR 為必要步驟。這取代 [ADR-0001](0001-local-news-interpretation.md) 的純本機與人工資料 PR 限制，允許免費 API 提供輔助；具體接點及實作狀態另記於下方，不改寫當時決策。

已確認相關的新聞可先公開來源標題、連結及待釐清狀態；事件身分、位置與傷亡欄位各自達到原文核對條件才用於對應地圖或統計。同案報導更新原事件，未解數值衝突保留既有已核對值並記錄新來源，未知數不填零；沒有原值時保持未明。這容許部分資訊延後採用，以換取新聞自動更新及可追溯的統計，不能將機器核對偽裝成人工複核。

本機與 GitHub Actions 共用流程；必要解析環境或資料驗證故障時保留既有網站並記錄失敗。此決策確認收錄與發布界線；採納決策、程式實作與正式部署是不同狀態。

## 實作註記（2026-11-03，尚未部署）

jieba 0.42.1、固定 `HMM=false` 與詞典 hash、酒精／毒品事件規則、records 的發布資格／同案整合／快照驗證，以及 GitHub publisher 與排程已實作。政策與統計目前固定只發布新聞卡；司法後續可嘗試連結既有事件。未核對 legacy 數值不自動成為已核對值；重新核對、數值更正與衝突須保留紀錄。

可選接點已採用 Gemini，模型由設定指定。程式對 `suggestions` 只核對原文引句及位置，不驗證語意關係、不改變 eligibility 或覆寫傷亡。`NEWS_API_MAX_REQUESTS` 是每次執行上限，不是每日硬額度。目前沒有設定金鑰或 API 實測，亦未量測模型效果。

正式部署與線上快照讀回尚未完成；程式存在不表示精確率或全自動語意理解已完成。狀態與限制見 [規劃](../daily-alcohol-drug-news-plan.md)，可執行的 CLI、發布前提與恢復操作以 [README](../../README.md#每日酒駕與毒駕新聞) 為準。
