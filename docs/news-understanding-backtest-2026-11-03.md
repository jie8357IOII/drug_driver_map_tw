## 尚未完成的理解範圍

未明示的車種、跨段日期、複雜親屬代稱與未具名傷者仍可能缺漏；保留空值及問題原因。沒有明確案件數或切換線索的多案新聞，仍可能漏拆；新的句型仍須回看。跨篇事故關聯、已存在網址的版本追蹤、傷亡後續更新尚未自動完成，因此資料仍需 PR 複核。

清單位於 `docs/news-backtest-urls.txt`，執行命令見 README 的「單篇分析與歷史文章回看」。使用 `--urls` 會讀取網站當時版本；需要比較同一份原文時，應保留 `sources.json` 並使用 `--input` 重跑。
